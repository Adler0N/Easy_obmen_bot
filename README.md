# Easy_obmen_bot

Telegram-бот для обмена валют в Нячанге.

## Переменные окружения
- `BOT_TOKEN` — токен от @BotFather
- `ADMIN_CHAT_ID` — ID группы для заявок
- `ADMIN_USER_IDS` — ID админов через запятую

## Команды
- `/start` — меню
- `/kurs` — курсы валют
- `/setkurs` — установить курс (только админ)
- `/cancel` — отменить текущее действие

## Запуск на BotHost
Главный файл: `bot2.py`
Python: 3.11
