# Easy_obmen_bot

Telegram-бот для обмена валют в Нячанге. Позволяет узнавать актуальный курс
и оформлять заявки на обмен, которые приходят в админ-чат.

## Возможности

- Просмотр курсов RUB / USD / USDT к вьетнамскому донгу (VND)
- Оформление заявки на обмен в 5 шагов с подтверждением
- Уведомления пользователя о статусе заявки (выполнена / отклонена)
- Управление курсами прямо из бота (без деплоя)
- Гибкое управление админами: список хранится в БД + супер-админы в .env

## Переменные окружения

| Переменная | Описание |
|-----------|----------|
| `BOT_TOKEN` | Токен от @BotFather |
| `ADMIN_CHAT_ID` | ID группы (с минусом), куда приходят заявки |
| `ADMIN_USER_IDS` | ID «супер-админов» через запятую. Не теряются при сбросе БД |

Шаблон — в `.env.example`. Реальные значения задаются в панели BotHost.

## Команды

### Для пользователей
| Команда | Где работает | Что делает |
|---------|--------------|------------|
| `/start` | Везде | Главное меню |
| `/kurs` | Везде | Актуальные курсы |
| `/cancel` | Только в личке | Отменить текущее действие |

### Для админов
| Команда | Где работает | Что делает |
|---------|--------------|------------|
| `/setkurs` | Только в личке | Пошаговый ввод курсов (RUB → USD → USDT) |
| `/setkurs rub 305` | Везде | Быстрая установка курса одной строкой |
| `/addadmin 123456789` | Везде | Добавить админа |
| `/deladmin 123456789` | Везде | Удалить админа (кроме супер-админов) |
| `/admins` | Везде | Список всех админов |

В пошаговом `/setkurs` можно ввести `-`, чтобы пропустить валюту без изменений.

## Запуск на BotHost

1. Создайте бота в панели BotHost.
2. Укажите репозиторий: `https://github.com/Adler0N/Easy_obmen_bot.git`
3. Главный файл: `bot2.py`
4. Python: 3.11
5. Добавьте переменные окружения: `BOT_TOKEN`, `ADMIN_CHAT_ID`, `ADMIN_USER_IDS`.
